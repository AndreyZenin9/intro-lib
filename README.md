# Библиотека разборов интро

Постоянное место хранения всех разборов интро YouTube-роликов.
Раньше они лежали россыпью в `~/workspace/_temp/`, где рано или поздно
были бы вычищены как временные.

**Открывать:** `index.html` в этой папке.

## Структура

```
intro-lib/
├── index.html        витрина: таблица сравнения, цепочки ходов, заметки
├── data.json         данные всех разборов — редактируется вручную
└── razbory/
    └── <videoId>/
        ├── index.html   сам разбор
        └── media/       видео, аудио, кадры
```

Каждый разбор — самодостаточная папка: перенеси её целиком, и всё
откроется. Витрина ссылается на `razbory/<videoId>/index.html`.

## Как добавить новый разбор

1. Сделать разбор по скиллу `youtube-intro-razbor`.
2. Скопировать рабочую папку в `razbory/<videoId>/`, оставив только
   html + `media/` (+ vtt, если нужен). Главный html назвать `index.html`.
3. Дописать объект в `data.json`. Поля:

```json
{
  "id": "videoId",
  "title": "Заголовок ролика",
  "author": "Канал или автор",
  "url": "https://www.youtube.com/watch?v=...",
  "theme": "Тема одной фразой",
  "date": "YYYY-MM-DD",
  "full_len": "29:40",
  "intro_len_s": 155,
  "cuts": 47,
  "avg_plan_s": 3.3,
  "wpm": 160,
  "words": 417,
  "thoughts": 14,
  "scenes": 22,
  "switch": "Слово-переключатель и таймкод",
  "chain": ["Ход 1","Ход 2","..."],
  "note": "Чем этот заход отличается от остальных — одна фраза"
}
```

Витрина подхватит запись сама, ничего в html править не надо.

Ходы в `chain` писать одинаковыми формулировками между роликами —
подсветка общих приёмов работает по точному совпадению текста
(регистр и кавычки игнорируются). «Снятие вины» и «снятие вины» —
один ход; «Снятие вины» и «Снимает вину» — два разных.

## Что показывает витрина

- **Таблица сравнения** — все цифры в ряд, заголовки колонок
  кликабельны для сортировки. Темп речи выше 200 слов/мин подсвечен.
- **Цепочки ходов** — последовательность приёмов каждого автора.
  Оранжевым — ходы, встречающиеся больше чем в одном ролике.
- **Чем каждый отличается** — по фразе на ролик.

## Размер

Медиа занимает основной объём (60–100 МБ на разбор с видео).
Если папка разрастётся — удалять `media/fragment.mp4` у старых
разборов, оставляя кадры и mp3: страница переживёт, плеер просто
не покажет видео.
